typeahead.waow.tech — architecture

The whole design in one line: a search never scans the corpus. It's bounded point-lookups into a precomputed snapshot plus a small live-overlay merge — independent of the 5.9 M-actor corpus size. Bluesky is rollback-only.

Three flows: ① ingest (firehose → ingest service → edge worker → source DB), ② build (source DB → snapshot builder → R2), ③ serve (user → edge worker → search service: bounded snapshot + overlay lookup). The edge worker is the public front door and the actor-write API — drawn as a two-role hub, not a link in a chain. Same Zig binary runs as the continuous ingest service and the ephemeral snapshot builder.
