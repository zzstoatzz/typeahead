# Matched engine qualification evidence — October 29, 2026

Historical JSON receipts from the matched native/Tantivy qualification trials.
Their contents are preserved byte-for-byte, including original paths and hashes;
those paths describe the original run, not current resource availability.

The [qualification tooling](../../../deploy/tantivy-qualification/README.md)
and its [image builder](../../../deploy/tantivy-qualification/image/README.md)
remain under `deploy/`. Controller resource ledgers and the native build receipt
remain beside that tooling because they are inputs, not just reports.

New trial outputs are ignored beside the tooling and do not overwrite this
collection. Preserve a qualified run’s bounded receipts under a dated evaluation
collection when recording its conclusions.
