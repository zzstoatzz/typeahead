# Documentation

- [How it works](how-it-works.md): the running system in five pictures.
- [Operating](operating.md): upgrade a slot, flip the route, roll back,
  moderation, index requests, statistics and what each alert means.
- [Development](development.md): local setup, tests and deploy commands.
- [Teardown](teardown.md): what is left over from the old system and has not
  been deleted yet.
- [Costs](../COSTS.md): what the running resources are and what they cost.
- [Repository instructions](../AGENTS.md): rules for changing the system.

The API is documented where apps read it: the
[API docs](https://typeahead.waow.tech/docs) and
[llms.txt](https://typeahead.waow.tech/llms.txt), both written in `src/pages/`.

The pictures are generated by [`diagrams/build.py`](diagrams/build.py).
[Community smoke testing](smoke-testing/README.md) has the prompt for testers.

Typeahead indexes public accounts only. Completing names inside a private
organization is the job of that organization's host.

[History](history/README.md) holds the plans, rollouts, retrospectives and
measurements from the Turso system and the move off it. Nothing there
describes the running system. New retrospectives go in `history/retros/`.
