# Reader-facing figures

Job: let a reader understand the traffic increase and snapshot-plus-changes
without interpreting infrastructure, tracing arrows, or learning chart gestures.
Do not change the article prose in this pass.

Palette: paper #ffffff, ink #172238, comparison blue #284bd6, old-data grey
#77869e, correction teal #096b59, stage wash #edf2ff. White controls with dark
text, visible blue selection, no low-opacity labels. System Helvetica Neue
for an ordinary readable editorial figure; numbers use tabular alignment.

Traffic: a comparison, not a timeline player. The quiet window stays beside
the selected voting window. Exactly two labeled buttons change the comparison;
no hover activation, scrubber, or competing gestures. Bar length changes show
scale; exact values remain readable. Same axes for both windows. Show searches
and typical engine time, define median in optional notes. Default busiest gives
the useful comparison without requiring interaction.

Index: a small worked example of a display-name change. A prepared index card
and a separate correction slip explain two layers through their visible content.
Readers rename Alex to Ari, then fold the correction into a newly prepared
index. Two search-result rows make the consequences visible at every state.
Movement connects the correction slip to the prepared card during consolidation;
no moving dots, provider boxes, flowing wires, or click-to-inspect taxonomy.

Critique: a three-tab systems tour would reproduce the rejected design even
with new colors. Removed that taxonomy. Avoid replay transport because this is
a causal interaction, not a video. Keep only the next meaningful action and
reset. Result labels and structure carry meaning independently of color.

Motion: finite, initiated by an explicit button, no automatic playback. When
reduced motion is preferred, commit the state immediately. Block repeat input
only for the short consolidation transition. No fabricated intermediate data.
Validate at Leaflet's actual 588 px width and at 360 px, then inside its HTML
embeds. The two widgets remain self-contained with no network dependency.
