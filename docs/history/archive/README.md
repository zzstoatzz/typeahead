# Archived designs and operations

These records explain superseded native-engine designs, migrations and incidents.
They are retained for reasoning and recovery context, not as runnable instructions.
Machine IDs, schedules, prices and claims of “current” or “production” apply only
to the dates in each record. Git history retains deleted or replaced material.

For the deployed system, use [architecture](../../architecture.md),
[operations](../../operations.md) and [snapshot refresh](../plans/automatic-snapshot-refresh.md).
Dated evaluations and incident retrospectives remain in their respective folders.
